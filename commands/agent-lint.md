# Линт конфигов агента

1. Путь из `$ARGUMENTS`, по умолчанию текущий проект и `${CLAUDE_PLUGIN_ROOT}`.
2. Запусти `npx -y agnix <путь>` по каждому пути. `--fix` передавай только если он есть в `$ARGUMENTS`.
3. Нет сети или npx упал, скажи одной строкой и остановись.

## Вывод

1. Ошибок нет, одна строка.
2. Есть. Сначала ошибки, потом предупреждения. Строка это `файл:строка`, правило и суть одной фразой.
3. Больше 15 предупреждений, покажи 15 самых важных и число остальных.

## Стиль

Правила из `${CLAUDE_PLUGIN_ROOT}/refs/style.md`.
