# Отчет за день

Сначала прочитай `${CLAUDE_PLUGIN_ROOT}/refs/style.md`.

## Шаг 1. Блоки времени

Запусти `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/worklog_blocks.py" $ARGUMENTS`. Получишь JSON с полями `date`, `has_journal`, `total_minutes`, `repos`, `blocks`. У блока `start`, `end`, `minutes`, `kind` (`work` или `call`), `task`, `title`, `topics`, `notes`, `repos`, `branches`.

Время, длительности и итог бери из JSON как есть. Сам не пересчитывай, не сдвигай, не склеивай и не дели блоки.

## Шаг 2. Суть блоков

1. По каждому репозиторию из `repos` коммиты за день. `git -C <repo> log --all --since="<date> 00:00" --until="<date> 23:59" --author="$(git -C <repo> config user.email)" --format="%cI %s"`.
2. Для `work` блока суть собери из `notes` (это мои чекпоинты, главный источник), `topics` (что я просил, там шум, выкидывай уточнения и отмены) и коммитов с временем внутри блока.
3. Для `call` блока суть это `title`.
4. Блоков нет, скажи одной строкой, что за этот день активности нет, и остановись.

## Формат

```
Отчет за 2026-10-03

09:30-10:45  1ч 15м  DEV-5279 поправил счетчик комментариев в карточке сделки
10:45-11:15  30м     дейлик
11:15-13:00  1ч 45м  DEV-5279 развел комментарии сделки и коммуникаций

Итого 3ч 30м
```

1. Строго в порядке времени, как в JSON.
2. Строка это `HH:MM-HH:MM`, два пробела, длительность `45м` или `1ч 15м`, выравнивание пробелами, суть.
3. Суть начинается с `task` для `work` блока. Дальше коротко что сделано, 1 фраза, до 80 символов.
4. Первое лицо единственного числа. Исправил, добавил, разобрался, собрал. Никаких мы и решили.
5. В конце `Итого` по `total_minutes`.
6. `has_journal` false, последней строкой «время восстановлено по активности».
7. Без ссылок на файлы.

## Сохранить

Запиши отчет в `~/.claude/worklog/<date>.report.md`, перезапиши если есть. Покажи отчет мне. Ничего не коммить.
