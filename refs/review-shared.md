# Общий чеклист

1. Контракт фронта и бэка. Изменилась схема GraphQL, значит перегенерированы типы клиента и поправлены запросы. Поле есть на одной стороне и нет на другой это `[API]`.
2. Секреты и токены не в коде, не в логах, не в сообщениях об ошибках.
3. Мертвый код, забытые `console.log` и `debugger`, неиспользуемые импорты и экспорты.
4. Локализация. Новые пользовательские строки во всех языках проекта, если проект многоязычный.
5. Документация. Дифф поменял поведение, API или инварианты, а `docs/`, `AGENTS.md` и `CLAUDE.md` не обновлены это `[док]`.
6. Комментарии в добавленном коде. По умолчанию код без комментариев. Комментарий оправдан, когда объясняет почему, а не что. Пересказ кода, заметки для этого коммита и закомментированный код лишние. Оставшиеся комментарии короткие, по правилам `refs/style.md`.
7. Тесты. Новая логика с ветвлениями покрыта. Тест проверяет поведение, а не реализацию.
