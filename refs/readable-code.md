# Читаемый код

Код читают чаще, чем пишут. Человек должен понять функцию сверху вниз за один проход, не держа в голове расшифровку имен.

Правила проекта из AGENTS.md, CLAUDE.md и конфига линтера важнее.

## Имена

1. Полные слова о смысле. `count`, `char`, `task`, `store`, `lastDigit`, а не `n`, `ch`, `fn`, `kv`, `mod10`.
2. Короткие имена только из списка. `i` и `j` для индекса в цикле, `id`, `url`, `db`, `x` и `y` для координат, `a` и `b` в компараторе сортировки.
3. Булево значение начинается с `is`, `has`, `can` или `should`. Функция начинается с глагола. Единица измерения в имени, `timeoutMs`, `sizeBytes`.
4. Функцию называют по назначению, алгоритм в комментарии. `hashString` с комментарием `cyrb53`, а не `cyrb53`.
5. Пары и счетчики одним шаблоном. `activeCount` и `peakCount`, а не `active` и `peak`.

## Абзацы

1. Тело функции разбито пустыми строками на шаги. Подготовка, основная работа, результат. Каждый шаг от 1 до 6 строк.
2. Функция длиннее 5 строк без единой пустой строки это сигнал, что шаги слиплись.
3. Условие из нескольких частей вынеси в булеву переменную с именем, `const isTeen = ...`.

## Числа

1. Число, смысл которого не виден из строки, получает имя. `const MAX_PARALLEL_REQUESTS = 6`.
2. Константы алгоритма собраны в одном месте с комментарием-ссылкой на источник.

## Форма

1. Ранний return вместо вложенного `else`. Вложенность не глубже 2 уровней.
2. Сигнатура длиннее 100 символов, по одному параметру на строку.
3. Функция держит один уровень абстракции. Смешались разбор строк и бизнес-правило, раздели.
4. Изменяемое состояние, общее для нескольких функций, называется и объясняется. `let nextIndex = 0` с комментарием, почему воркеры делят его.

## Комментарии

По умолчанию код без комментариев. Комментарий объясняет почему или дает ссылку на источник, а не пересказывает код.

## Пример

До.

```ts
export function plural(n: number, forms: readonly [string, string, string]): string {
  const mod10 = n % 10
  const mod100 = n % 100
  if (mod10 === 1 && mod100 !== 11) return forms[0]
  if (mod10 >= 2 && mod10 <= 4 && (mod100 < 12 || mod100 > 14)) return forms[1]
  return forms[2]
}
```

После.

```ts
export function plural(count: number, forms: readonly [one: string, few: string, many: string]): string {
  const [one, few, many] = forms
  const lastDigit = count % 10
  const lastTwoDigits = count % 100

  const isTeen = lastTwoDigits >= 11 && lastTwoDigits <= 14
  if (isTeen) return many

  if (lastDigit === 1) return one
  if (lastDigit >= 2 && lastDigit <= 4) return few
  return many
}
```

Имена говорят о смысле, исключение для 11-14 названо и стоит первым шагом, шаги разделены пустыми строками.
