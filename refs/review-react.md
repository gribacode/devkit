# Чеклист React

1. `useEffect`. Полный список зависимостей. Эффект не синхронизирует то, что можно посчитать при рендере. Есть очистка для подписок, таймеров, AbortController.
2. Устаревшие замыкания. Колбэки в таймерах, подписках и обработчиках не держат старое состояние. Нужен функциональный `setState` или ref.
3. `key` в списках стабильный и уникальный, не индекс при изменяемом порядке.
4. Производное состояние. Значение, которое считается из props или другого состояния, не лежит в `useState` и не синхронизируется эффектом.
5. Гонки загрузки. Ответ старого запроса не перетирает новый. Отмена при размонтировании и смене параметров.
6. Мемоизация. `useMemo` и `useCallback` только там, где есть измеримая польза или стабильная ссылка нужна дочернему `memo`. Лишняя мемоизация это шум, недостающая это лишние рендеры тяжелых деревьев.
7. Контролируемые поля. Нет переключения между controlled и uncontrolled, нет `value` без `onChange`.
8. Доступность. Интерактив через `button` и `a`, а не `div` с `onClick`. Подписи у полей, `alt` у картинок, фокус после открытия модалки.
9. Ошибки. Error boundary вокруг независимых зон, загрузка и ошибка обработаны в UI, а не только успех.
10. Границы слоев FSD, если проект на FSD. Импорты только вниз по слоям и через публичный API слайса.
11. Для производительности сверься со скиллом `vercel-react-best-practices`, если он доступен.
